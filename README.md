# Malist · releases

Aqui ficam os APKs do **Malist**, um cliente Android para AniList e MyAnimeList com uma lista unificada: cada edição é gravada nos dois serviços ao mesmo tempo.

**[Baixar a versão mais recente](https://github.com/Hudss42/malist-releases/releases/latest)** · Android 8.0 ou mais novo.

- Cada versão nova instala por cima da anterior, sem perder logins e lista.
- A partir da 0.9.0, o próprio app avisa quando sai uma versão nova.
- As notas de cada versão estão em [`notas/`](notas/) e na página de cada release.
